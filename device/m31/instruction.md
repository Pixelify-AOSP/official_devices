### Before start flashing

- Always have backup of your internal storage
- Use Official TWRP or ROM specific Recovery
- Download latest stock firmware


### First time installation (clean flash):
- Flash stock firmware in download mode
- Flash recovery
- Format data
- Wipe Dalvik/Art Cache,cache
- Reboot to recovery
- Wipe Dalvik/Art Cache,cache
- Flash the ROM
- Flash the Nikgapps (Note: Flash if you need Google apps)
- FLash Everline-KSUN (Note: If need KSU-Next)
- Tap on format data, type yes and reboot to system

### Update installation:
#### Via recovery (recommended way):
* Reboot to recovery
* Sideload rom.zip
* Wipe cache and reboot to system

#### Via OTA:
* Go to Settings -> System -> Updater and download latest build
* Choose install and let it finish
* Reboot to system
